# Brand — RBOLA (interim)

_Status: interim — minimal palette from `carspotting/brand-direction.md`; full identity lands with the coin renders + brand step._

## Name

**RBOLA** (always all-caps in Latin) paired with **რბოლა** (Georgian, "race"). Pronunciation "r-BO-la". The name is the in-game catch verb — "RBOLA!" stamps the screen on a successful catch.

## Palette (dark-only for now)

| Token | Value | Use |
|---|---|---|
| `surface` | `#16181c` | Gunmetal app background |
| `surface-raised` | `#1e2127` | Cards, inputs, raised panels |
| `line` | `#3a3f47` | Borders, dividers |
| `accent` | `#f0a500` | Amber — primary actions, the RBOLA! stamp, wordmark |
| `foreground` | `#e5e5e5` | Body text |
| muted text | neutral-400/500 | Secondary text (keep ≥ AA contrast on surface) |

Amber is used sparingly: primary action + brand moments only. On amber, text is black.

## Voice

Race energy at the surface, collector precision at the core. No cuteness in anything touching money, rarity, or the marketplace. Copy: short, active, specific.

## Type

System/Geist sans for UI (scaffold default). Wide tracking on the RBOLA wordmark. Numbers and addresses: mono + tabular-nums.
